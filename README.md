## 👨‍💻 Обо мне

- 🔭 Разрабатываю веб-приложения и интерфейсы под ключ — от вёрстки до серверной части.
- 🖥️ Умею создавать **CEF-интерфейсы** (Chromium Embedded Framework) — встраиваемые UI для игр и десктоп-приложений.
- 🧩 Работаю с современным фронтендом: **React / Vue / TypeScript**, сборкой через **npm**.
- 🗄️ Пишу серверную логику на **PHP** и работаю с базами данных **MySQL**.
- 💬 Всегда рад интересным проектам и коллаборациям.
